# FestivalTools 2026

Static, SEO-first festival information website generated with HTML, CSS and vanilla JS.

## Before publishing
1. Replace https://www.example.com/ with the real domain in canonical tags, Open Graph URLs, sitemap.xml and robots.txt.
2. Verify all festival dates for your target regional Panchang.
3. Add verified Muhurat/Tithi/Bhadra/city timing values in assets/js/festival-data.js.
4. Replace placeholder contact/privacy/terms text with your actual legal and contact details.
5. Submit sitemap.xml in Google Search Console.
6. For Blogger, use the same page HTML as a template and replace relative .html links with the actual Blogger Page/Post URLs. Do not use hash routing.

## Important date note
The 2026 featured dates in this starter are based on published 2026 calendar references. Dussehra and some observances can differ by regional tradition, so verify before publishing a definitive claim.


## Advanced SEO notes
- `llms.txt` is included as an optional machine-readable file for other AI/agent systems. Google says llms.txt is not needed for Google Search and does not improve rankings; normal SEO remains foundational.
- `llm.txt` is included only as a compatibility copy because the requested filename was mentioned; `/llms.txt` is the canonical version.
- AI image placeholders live under `assets/images/`; generate original images using `assets/images/prompts.md`, then save them with the exact filenames used by the HTML.
- Replace `example.com` in canonical, Open Graph, sitemap, robots and llms files with the live domain.
- Verify all city timing data against the intended Panchang and date immediately before publication.
