## Image SEO checklist
- Convert final images to WebP or AVIF.
- Keep hero images reasonably compressed.
- Use descriptive filenames.
- Add width and height attributes in HTML to reduce layout shift.
- Use loading="lazy" below the fold.
- Do not use AI-generated images as a substitute for original festival information.
- Add meaningful alt text describing the actual image.
